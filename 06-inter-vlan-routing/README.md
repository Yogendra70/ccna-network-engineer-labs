# Inter-VLAN Routing Labs

This folder contains CCNA labs related to inter-VLAN routing using different methods.

## Labs Included
- Inter-VLAN Routing using Router-on-a-Stick (ROAS)
- Inter-VLAN Routing using Switch Virtual Interface (SVI)
- Inter-VLAN Routing using ROAS and SVI (Comparison)

## Skills Practiced
- VLAN creation and assignment
- Sub-interface configuration
- 802.1Q encapsulation
- SVI configuration on Layer 3 switch
- Inter-VLAN connectivity verification
