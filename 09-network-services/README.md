# Network Services Labs

This folder contains CCNA labs related to common network services used in enterprise networks.

## Labs Included
- Network Time Protocol (NTP)
- SYSLOG Configuration
- Simple Network Management Protocol (SNMP)

## Skills Practiced
- Time synchronization using NTP
- Centralized logging using SYSLOG
- Network monitoring using SNMP
- Verification and troubleshooting of network services
