# CCNA Network Engineer Labs

This repository contains hands-on CCNA networking labs created using Cisco Packet Tracer.
The labs demonstrate practical understanding of routing, switching, VLANs, subnetting,
and basic network troubleshooting.

## Skills Covered
- OSI and TCP/IP Models
- IP Addressing and Subnetting
- VLAN and Inter-VLAN Routing
- Static Routing
- STP Fundamentals
- Ethernet, ARP, and MAC Addressing
- Network Troubleshooting (Ping, Traceroute)

## Tools Used
- Cisco Packet Tracer
- Windows
- Linux (Ubuntu)

## Repository Structure
- 01-management-access – Telnet and SSH labs
- 02-dhcp – DHCP server, router, and relay labs
- 03-routing – Static, default, RIP, floating static routing
- 04-dynamic-routing – EIGRP and OSPF labs
- 05-switching – VLAN, trunking, VTP, port security, EtherChannel
- 06-inter-vlan-routing – ROAS and SVI
- 07-nat – Static NAT, Dynamic NAT, PAT
- 08-security – Standard and Extended ACLs
- 09-network-services – NTP, SYSLOG, SNMP
- 10-high-availability – HSRP
- 11-ipv6 – IPv6 static routing
- 12-wireless – Wireless configuration
- 13-device-recovery – Router recovery
