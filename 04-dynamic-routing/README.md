# Dynamic Routing Labs

This folder contains CCNA dynamic routing labs implemented using Cisco Packet Tracer.

## Labs Included
- EIGRP (Single Autonomous System)
- EIGRP (Multiple Autonomous Systems)
- OSPF Single Area
- OSPF Multi Area

## Skills Practiced
- Dynamic routing protocol configuration
- EIGRP metric and AS configuration
- OSPF area design and router ID
- Route verification and troubleshooting
