# Switching Labs

This folder contains CCNA switching labs using Cisco Packet Tracer.

## Labs Included
- VLAN Configuration
- Trunking and Native VLAN
- Allowed VLAN Configuration
- VTP Configuration
- Port Security
- DHCP Snooping
- EtherChannel

## Skills Practiced
- VLAN creation and assignment
- Access and trunk port configuration
- Switch security implementation
- Layer 2 troubleshooting
